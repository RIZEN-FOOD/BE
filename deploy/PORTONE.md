# 포트원(PortOne V2) 연동 설정

코드는 준비돼 있다. 콘솔에서 값을 받아 서버 `.env` 에 넣으면 켜진다(프론트 재배포 불필요).

    결제 흐름
    브라우저 ─ 결제창(포트원 SDK, 결제수단별 채널) ─> PG
       │ 결제 완료
       ├─> POST /api/orders/{주문번호}/pay  ─┐
       │                                     ├─ 서버가 포트원 API 로 결제를 다시 조회 → 상태 PAID·금액 대조 → 확정
    포트원 ─> POST /api/payment/webhook/portone ┘   (둘 중 먼저 온 쪽이 확정, 나머지는 그대로 통과)
       │
       └ 둘 다 못 오면 30분 자동 정리가 포트원을 조회해 확정 또는 재고 복구

## 1. 콘솔에서 받을 값

| .env | 콘솔 위치 | 비고 |
|---|---|---|
| `PORTONE_STORE_ID` | 결제 연동 → 연동 정보 → 식별코드·API Keys | `store-...` 공개값 |
| `PORTONE_API_SECRET` | 같은 화면 → **V2 API Secret** 발급 | ★ 서버 전용. 프론트·저장소 금지 |
| `PORTONE_CHANNEL_KEY` 등 | 결제 연동 → 연동 정보 → 채널 관리 → 채널 추가 | 결제사마다 채널이 따로다 (아래 2) |
| `PORTONE_WEBHOOK_SECRET` | 결제 연동 → 연동 정보 → 웹훅 | ★ 서버 전용. `whsec_...` |

## 2. 채널 — 결제수단마다 따로

| 결제 화면 | .env | 채널 |
|---|---|---|
| 신용·체크카드 | `PORTONE_CHANNEL_KEY` | PG 채널 (토스페이먼츠·KG이니시스·NHN KCP 등 계약한 PG) |
| 계좌이체 | `PORTONE_CHANNEL_KEY_TRANSFER` | 보통 카드와 같은 PG 채널 키 |
| 카카오페이 | `PORTONE_CHANNEL_KEY_KAKAOPAY` | 카카오페이 채널 (별도 계약) |
| 네이버페이 | `PORTONE_CHANNEL_KEY_NAVERPAY` | 네이버페이 채널 (별도 심사·계약) |
| 토스페이 | `PORTONE_CHANNEL_KEY_TOSSPAY` | 토스페이 채널 |

**비워 둔 결제수단은 결제 화면에 나오지 않는다.** 계약이 끝난 것부터 하나씩 채우면 된다.

## 3. 웹훅

- 주소: `https://www.도메인/api/payment/webhook/portone` (Caddy 가 화면 서버를 거치지 않고 API 로 원본 그대로 보낸다)
- 버전: 최신(2024-04-25 이후) — 본문 `data.paymentId` 를 쓴다
- 콘솔의 "웹훅 테스트 호출" 로 한 번 보내 보고 서버 로그에서 확인한다
  - `포트원 웹훅 ... 결과=NOT_FOUND` → 서명 통과(테스트 결제번호라 주문이 없을 뿐) ✅
  - `포트원 웹훅 서명 검증 실패` → 시크릿이 틀렸다

## 4. 테스트 순서 (테스트 채널)

콘솔에서 **테스트 모드 채널**부터 만든다. 실제 돈이 빠지지 않는다.

1. `.env` 에 테스트 채널 값 + `PAYMENT_PROVIDER=portone` → API 재시작
2. 카드 결제 → 주문 상세 "결제 완료" / 관리자 주문 목록 "결제 완료"
3. 결제창을 닫기 → "결제가 취소되었습니다", 재고 원복, 장바구니 유지
4. 결제 후 **바로 창 닫기**(확정 요청 누락 흉내) → 웹훅으로 수 초 안에 "결제 완료"
5. 관리자에서 취소 완료 → 포트원 콘솔에 환불 기록
6. 모바일(휴대폰 브라우저)로 2·3번 반복 — 결제 후 `/checkout/complete` 로 돌아오는지

통과하면 실채널(실제 계약 MID)로 키만 바꾼다.

## 5. 아직 없는 것

- **가상계좌(무통장)**: 입금이 나중에 확인되는 방식이라 웹훅의 입금 알림 처리를 더 붙여야 한다
- **정기결제(빌링키)**: 별도 기능·계약. 요건이 정해지면 설계한다
- 포트원 콘솔에서 **직접** 취소한 결제는 주문에 자동 반영하지 않는다(취소 기록은 관리자 화면에서 남겨야 한다). 서버 로그에 "관리자 확인 필요" 경고가 남는다
